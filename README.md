# Canadian Direct Democracy

This project provides a small front-end demonstration of a Canadian direct democracy platform. The design uses a clean white and red theme with subtle animations and small Canadian flags in the header.

## Features
- **Vote Now** – the homepage asks "Do you support Bill C-2 (Strong Borders Act)?" with Yes/No buttons and a confirmation modal.
- **Latest bills** – `index.html` lists recent Canadian parliamentary bills with highlighted sections and explanations. Each bill links to its full text.
- **Commenting** – visitors can leave comments on individual bills. Comments are stored locally in the browser.
- **Voting** – each bill has upvote and downvote buttons with counts saved locally.
- **Responsive design** – smooth animations and a minimal layout work well on mobile and desktop.

The project is built with plain HTML, CSS and vanilla JavaScript to allow easy future upgrades.
